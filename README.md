# Карточка

Мобильное веб-приложение для хранения скидочных карт. Работает локально и может синхронизировать карты между устройствами через Supabase.

## Что работает

- ручное добавление карт;
- сканирование камерой и распознавание кода на изображении;
- Code 128, EAN-13 и QR-коды;
- поиск и выбор дизайна портмоне;
- установка как PWA и базовый офлайн-режим;
- вход по email и одноразовому коду;
- облачная синхронизация с защитой строк на уровне пользователя.

## Настройка облака

1. Создайте проект на Supabase.
2. Откройте **SQL Editor** и выполните весь файл `supabase.sql`.
3. В **Authentication → Providers → Email**:
   - включите Email provider;
   - для входа именно кодом измените шаблон письма Magic Link так, чтобы в нём использовался `{{ .Token }}`, а не только ссылка.
4. В **Project Settings → API** скопируйте:
   - Project URL;
   - публичный `anon` / publishable key.
5. Вставьте их в `config.js`.
6. Никогда не добавляйте во фронтенд `service_role` key.

После публикации пользователь вводит почту, получает код, входит и синхронизирует свои карты. Политики RLS не позволяют читать чужие записи.

## Локальный запуск

Приложение статическое. Запускайте его через HTTP-сервер, а не открытием `index.html` как файла:

```powershell
npx serve .
```

или любым другим локальным сервером.
