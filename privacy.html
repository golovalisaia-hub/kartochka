ККарточка

Политика конфиденциальности

Редакция от 24 сентября 2026 года

Настоящая Политика описывает, какие данные обрабатывает сервис «Карточка» (далее — Сервис) и для чего. Описаны только те данные, которые Сервис действительно обрабатывает.

1. Какие данные обрабатываются

Данные аккаунта Telegram. При входе через Telegram Сервис получает идентификатор пользователя Telegram, имя и, если оно задано, username. Эти данные приходят от Telegram в подписанном виде и проверяются на сервере. Номер телефона Telegram Сервис не запрашивает и не получает.

Электронная почта. При входе по почте обрабатывается адрес, указанный Пользователем, и одноразовый код подтверждения.

Данные карт лояльности. Сервис хранит добавленные Пользователем карты: название магазина, номер карты или содержимое штрихкода либо QR-кода, формат кода и цветовое оформление карточки.

Изображения карт. Если Пользователь добавляет карту фотографией или выбирает изображение из галереи, изображение кода сохраняется вместе с картой и используется для её отображения. Распознавание штрихкода выполняется непосредственно на устройстве Пользователя средствами браузера; отдельная серверная система распознавания не используется, и фотография не передаётся сторонним сервисам распознавания.

История открытий. Сервис сохраняет время последнего открытия карты, чтобы показывать недавно использованные карты первыми. Факт покупки Сервису неизвестен.

Общий доступ к картам. Если Владелец разрешил использование своей карты другими Пользователями, Сервис хранит сам факт разрешения, время его включения и отключения, а также количество и время показов карты. Эти сведения нужны для равномерного распределения показов между Владельцами.

Обращения в поддержку. Сохраняются номер обращения, текст обращения, идентификатор Пользователя, время создания и статус обращения.

Технические данные. Обрабатываются служебные сведения, необходимые для работы: идентификаторы сессий, отметки времени запросов, сведения о синхронизации и записи об обращениях к разделу карт сообщества для защиты от чрезмерной нагрузки.

Платёжные данные. Реквизиты банковских карт и иные платёжные данные вводятся на стороне платёжного провайдера и на серверы Сервиса не передаются и не хранятся. Сервис получает от провайдера только сведения о статусе платежа и сроке доступа.

2. Зачем обрабатываются данные

  • предоставление работы кошелька: хранение, отображение и синхронизация карт;
  • разграничение доступа, чтобы карты одного Пользователя не были видны другому;
  • работа раздела карт сообщества и равномерное распределение показов;
  • обработка обращений в поддержку;
  • обеспечение безопасности и защита от злоупотреблений;
  • предоставление платного доступа после подключения приёма платежей.

Сервис не использует данные карт лояльности для рекламы и не продаёт их.

3. Кому передаются данные

Данные передаются только техническим поставщикам, без которых работа Сервиса невозможна:

  • поставщику размещения базы данных и серверных функций — для хранения карт и аккаунтов;
  • поставщику хостинга веб-приложения — для доставки приложения на устройство;
  • Telegram — в объёме, необходимом для работы бота и Mini App;
  • платёжному провайдеру — сведения, необходимые для проведения платежа, после подключения приёма платежей.

Данные могут быть переданы в иных случаях, прямо предусмотренных применимым законодательством.

4. Что видят другие пользователи

Если Владелец включил общий доступ к карте, другой Пользователь получает данные карты, необходимые для её предъявления на кассе. При этом:

  • Владелец не узнаёт, кто именно воспользовался его картой;
  • Пользователь, получивший карту, не узнаёт, кому она принадлежит: ни имени, ни username, ни идентификатора Владельца не передаётся;
  • Владелец видит только обезличенную статистику: количество показов и время последнего показа.

Карты, для которых общий доступ не включён, другим Пользователям не передаются ни при каких условиях.

5. Хранение и защита

Данные хранятся, пока Пользователь пользуется Сервисом. Доступ к данным на уровне базы данных разграничен: строки одного Пользователя недоступны другому. Обращение к картам сообщества возможно только через защищённые серверные функции с проверкой прав.

Серверные ключи и токены хранятся только в защищённом хранилище и не передаются в браузер. Номера карт и содержимое штрихкодов не записываются в журналы, в адреса страниц и в сообщения об ошибках.

6. Удаление данных

Пользователь может удалить любую свою карту в приложении — она удаляется, в том числе с других устройств, и автоматически исключается из общего доступа. Для удаления аккаунта и связанных с ним данных следует обратиться в поддержку через раздел «Информация».

7. Обращения

Вопросы об обработке данных принимаются в разделе «Информация» → «Поддержка» в боте.
