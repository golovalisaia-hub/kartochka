# Карточка — приватная проверка в Telegram (НЕ production)

Этот пакет является тестовой веткой. **Не объединять в `main` и не запускать публично**. Не использовать настоящие номера карт или настоящие платежи.

## Непременные условия

* Владелец создаёт бота через @BotFather и задаёт кнопку Mini App. Бот-токен вводится только в Supabase Edge Functions Secrets; не пересылать в чате и не добавлять в git.
* Для отдельного staging URL потребуется HTTPS-хостинг, не заменяющий опубликованный GitHub Pages `main`. Staging-база отдельно от production.
* Telegram login должен проверять подписанные initData; webhook — секретный заголовок. Операции с личными картами требуют серверной авторизации.
* Настоящая оплата отключена до устранения и полноценного тестирования обработки платежей.
* Все политики обмена магазинов по умолчанию запрещают публикацию. Для тестов использовать вымышленные карты в изолированной тестовой базе.

## Известные ограничения

* Безопасное объединение Telegram-аккаунта с существующим email-кошельком пока не реализовано. Не использовать текущий аккаунт с реальными картами для испытаний.
* Отвязка Telegram без проверенного альтернативного способа входа запрещена.
* Настоящая модерация карт не автоматизирована; не публиковать реальные коды до проверки.
* Не применять миграцию к рабочей базе до полноценного тестирования.

## Что можно проверять в закрытом контуре

Вход Mini App, интерфейс личного кошелька на вымышленных данных, отказ в доступе к каталогу без Premium и отказ в проведении реального платежа. Это не означает проверку работы карт на кассах, платежей и синхронизации между реальными устройствами.

## Статус импорта

Эта ветка первоначально содержит только документацию безопасности. Полный исправленный исходный код из Git bundle должен быть импортирован отдельно и сверен с тестами перед созданием работающего превью. Отсутствующие файлы нельзя считать установленными или запущенными.
