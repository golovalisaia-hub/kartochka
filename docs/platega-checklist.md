# Чек-лист Platega: что сделано и что остаётся владельцу

Документ составлен по фактическому коду репозитория, а не по намерениям.
Дата сверки: 24 сентября 2026 года.

## Коротко

К повторной подаче проект **не готов из-за одного пункта — не задана стоимость**.
Все остальные требования закрыты в коде. Цену может определить только владелец,
подставлять произвольное число нельзя: банк сверяет заявленный тариф с фактическим списанием.

## Требования проверяющего

| Требование | Где закрыто | Статус |
| --- | --- | --- |
| Политика конфиденциальности | `privacy.html`, ссылка в боте: `ℹ️ Информация → 🔒 Политика конфиденциальности`, прямой адрес `<адрес приложения>/privacy.html` | готово |
| Пользовательское соглашение | `terms.html`, ссылка в боте: `ℹ️ Информация → 📄 Пользовательское соглашение` | готово |
| Контакт поддержки (группа не подходит) | Обращение создаётся внутри бота: `ℹ️ Информация → 🆘 Поддержка → ✍️ Написать обращение`. Обращению присваивается номер, переписка хранится в `support_tickets` и видна только автору (RLS). Это не группа и не чат общего доступа | готово |
| Актуальные цены и тарифы | Экран `💳 Тариф и оплата`: состав платного доступа, что бесплатно, условия | **блокер: сумма не задана** |
| Убрать персональные данные (ИП, ООО, ИНН) | В документах их нет — проверяется тестом `tests/legal-pages.cjs` | готово в репозитории, **канал — за владельцем** |
| Кодовое слово `pay` | Строка «Код проверки: pay» в разделе `ℹ️ Информация`. Включается переменной `PLATEGA_REVIEW_MODE`, **по умолчанию включена**; выключается значением `false` | готово |
| Раздел «Информация» отдельными кнопками | Четыре самостоятельные кнопки — тариф, соглашение, политика, поддержка — плюс «Назад». Не свалены в один пункт меню | готово |
| Не публиковать выдуманную цену | `amount: null`, интерфейс честно пишет «Стоимость уточняется» и суммы не называет | готово |
| Подписка или разовый платёж | Определено по коду, а не по названию таблицы: `has_community_access` требует непросроченный `expires_at`, при этом ни планировщика, ни rebill, ни хранения платёжного токена в проекте нет. Значит **разовая оплата за период, без автопродления** (`ACCESS_MODEL = 'one_time_period'`) | готово |

Приём реальных платежей в проекте не подключён: платный доступ не продаётся, списаний нет.
Экран тарифа говорит об этом прямо, пока цена не опубликована.

## Что должен сделать владелец

1. **Задать цену — это и есть блокер.** Поле `amount` (целое число в рублях) в двух файлах,
   которые обязаны совпадать:
   - `pricing.js`
   - `supabase/functions/_shared/pricing.ts`

   Копия нужна потому, что Supabase собирает только каталог `supabase/functions`, и импорт из
   корня репозитория сломал бы задеплоенную функцию. Расхождение между копиями ловится тестом
   в `tests/legal-pages.cjs`, так что незаметно разъехаться они не могут.

   Там же при необходимости проверить `periodDays` (сейчас 30) и `autoRenew` (сейчас `false`).
   Если появится настоящее автопродление, модель доступа и тексты нужно менять вместе с кодом —
   иначе описание разойдётся с фактическим списанием.

2. **Проверить Telegram-канал** на упоминания ИП, ООО и ИНН, включая дубли постов на других
   языках. Из этой среды доступа к каналу нет, проверить оттуда невозможно.

3. **Выкатить изменения:** применить миграции, задеплоить Edge Function, вызвать `{"action":"setup"}`.
   Порядок описан в `docs/telegram-deploy.md`.

4. **Убедиться, что Production на Vercel открыт публично.** Пока на деплое включена защита,
   Telegram показывает в приложении страницу входа хостинга вместо «Карточки» — именно этот
   баг был в первом обращении. Функция теперь отказывается публиковать такой адрес и возвращает
   ошибку вместо тихой поломки; проверить текущее состояние можно вызовом `{"action":"diagnose"}`.

5. **Ответить на вопрос Platega** про подключение в качестве основной кассы. Это коммерческое
   решение владельца, за него никто отвечать не может.

## Чего проверка кодом не заменяет

Всё перечисленное проверено автотестами и на настоящем PostgreSQL. Живого Telegram на устройстве
в этой среде нет — исходящие запросы к `api.telegram.org` и Supabase заблокированы политикой.
Поэтому экраны бота, кнопки и оплату нужно один раз пройти руками на телефоне после выката.
