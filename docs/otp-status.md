# Статус почтового входа

На клиенте используются запросы `/auth/v1/otp` и `/auth/v1/verify` — вход по почте и коду, без пароля. Если на почту приходит ссылка, а не шестизначный код, исправьте шаблоны в настройках Supabase по инструкции [email-code-setup.md](email-code-setup.md).

Ни успешный HTTP-ответ, ни автоматические тесты с имитацией API не доказывают доставку настоящих писем. До проверки письма на реальном адресе и синхронизации между устройствами этот функционал не считается полностью проверенным. Не используйте личные номера карт в тестах.
